# 🍿 Concession Stand Program

An interactive **Python concession stand program** that allows customers to browse a menu, select multiple products, choose quantities, and receive a formatted receipt with their final total.

## ✨ Features

* 🍿 30 different food, snack, drink, dessert, and combo options
* 📋 Organized menu with product categories
* 🛒 Add multiple items to one order
* 🔢 Choose the quantity of each item
* 💰 Automatically calculate item subtotals
* 🧾 Generate a formatted table-style receipt
* 💵 Calculate the final order total
* ❌ Validate menu choices and quantities
* 🔄 Interactive console-based ordering system

## 🚀 How It Works

1. The program displays the concession stand menu.
2. The customer chooses a product.
3. The program asks for the quantity.
4. The selected item is added to the order.
5. The customer can continue adding products.
6. Choosing `0` starts checkout.
7. The program generates a formatted receipt.
8. The receipt displays each item's price, quantity, subtotal, and the final total.
